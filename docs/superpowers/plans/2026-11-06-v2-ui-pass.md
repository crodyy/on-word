# V2 UI Pass Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Reskin the shipped V1 forum to a strict black-and-white theme with a shared header (lotus logo, theme toggle, profile button) and JetBrains Mono everywhere.

**Architecture:** Restyle only. No API, contract, or backend changes. Theme is CSS variables plus a `dark` class on `<html>` persisted in localStorage; one new `SiteHeader` client component mounted in the root layout; logo served from `public/`.

**Tech Stack:** Next.js 14 App Router, Tailwind v4 (`@theme` tokens), `next/font/google` (JetBrains Mono), Phosphor icons, `next/image` or plain `img` for the logo.

**Spec:** This conversation (V2 scope as agreed 2026-11-06): strict `#000`/`#fff` only with hierarchy via size and weight, exact-inverse dark mode with toggle, header with logo left and theme toggle plus profile button right, profile dropdown (full address, copy, disconnect; links to signup when unbound), JetBrains Mono everywhere. Logo file: `upload_scpi_upk.jpg` (735x649 pink pixel lotus) from the user. My call, stated in the plan: the logo file is used unchanged (pink), as the single color on the site; the user never approved altering their artwork. Accent color is deleted; muted text becomes full-ink at smaller sizes; borders become solid currentColor ink.

## Global Constraints

- No backend, API, contract, or test-file changes in this plan. If a component needs data, it uses the existing contract (`lib/types.ts`) unchanged.
- Only two colors ship in CSS: `#000` and `#fff`. No grey hex, no opacity-based grey text. (The logo image is exempt.)
- Zero em-dashes or en-dashes in any visible string.
- Phosphor is the only icon library. No hand-rolled SVG icons.
- One typeface: JetBrains Mono, via `next/font/google`.
- Motion uses `transform` and `opacity` only; `prefers-reduced-motion` guard stays.
- Every task ends green: `npx tsc --noEmit` clean and `npm run build` passes.

## Review Focus

- Toggle flash on load (dark class applied after paint): expect no white flash when stored theme is dark; fixed by an inline blocking script in the layout setting the class before paint.
- Copy button feedback (clipboard write): expect visible confirmation; clipboard API can reject without permissions, so failure must fail silent with the address still selectable.
- Dropdown dismissal (click-outside and Escape): expect the profile menu to close on outside click and Escape, and to return focus sensibly.
- Logo on dark background (pink lotus on black): expect it to still read; white JPEG background box would show, so the task specifies checking the file background and handling it.
- Pages without the header context (direct navigation): expect toggle and profile state to agree everywhere, since state lives in one component with localStorage.

## File Structure

- `public/logo.jpg`: the user-supplied lotus, copied unchanged.
- `app/globals.css`: tokens collapse to black/white plus dark inverse; accent and muted ramps deleted; placeholder and border rules updated.
- `app/lib/theme.ts`: `getStoredTheme`, `applyTheme`, `toggleTheme` helpers (localStorage + document class).
- `app/components/SiteHeader.tsx`: logo + wordmark left; theme toggle + profile button right; dropdown menu.
- `app/layout.tsx`: load JetBrains Mono, mount `SiteHeader`, keep the footer (one line).
- `app/**/page.tsx`: delete local eyebrow headers where the site header now covers them; replace muted/accent classes with ink-based ones; borders to solid ink.
